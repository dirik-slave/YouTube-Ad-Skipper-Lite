# YouTube Ad Skipper — Lite

A minimal Chrome extension (Manifest V3) that does exactly one thing: **skips video ads in the YouTube player**. No popup, no permissions, no analytics.

## Install

1. Clone or download this repo.
2. Open `chrome://extensions` → enable **Developer mode**.
3. **Load unpacked** → select the repo folder.
4. Open YouTube. Ads are skipped automatically.

Works in Chrome, Edge, Brave, and other Chromium-based browsers with Manifest V3 support.
